គីមីវិទ្យា ថ្នាក់ទី ១០

គីមី គឺជាវិទ្យាសាស្ត្រសិក្សាពីរូបធាតុ និងបម្លែងរបស់វា។ ទំព័រនេះប្រមូលចំណុចសំខាន់ៗដែលសិស្សត្រូវចេះ ពីជំពូកទាំង ៤ នៃសៀវភៅ។

ជំពូកទី ១អាតូម ជំពូកទី ២តារាងខួបនៃធាតុគីមី ជំពូកទី ៣សម្ព័ន្ធគីមី និងទម្រង់អង្គធាតុរឹង ជំពូកទី ៤គីមីសរីរាង្គ

១. អាតូម ច្បាប់គ្រឹះ និងដាល់តុន ភាគល្អិតក្នុងអាតូម អ៊ីសូតូប ស្រទាប់អេឡិចត្រុង ម៉ូល ២. តារាងខួប ក្រុម និងខួប លោហៈអាល់កាឡាំង អាឡូសែន ឧស្ម័នកម្រ លោហៈឆ្លង ៣. សម្ព័ន្ធគីមី សម្ព័ន្ធកូវ៉ាឡង់ សម្ព័ន្ធអ៊ីយ៉ុង ទម្រង់អង្គធាតុរឹង ៤. គីមីសរីរាង្គ ប្រេងកាត អាល់កាន អាល់សែន និងអាល់ស៊ីន បង់សែន ជីគីមី សំណួរ និងលំហាត់

អាតូម

១.១ច្បាប់គ្រឹះ និងទ្រឹស្តីអាតូមរបស់ដាល់តុន

ច្បាប់រក្សាម៉ាស

ច្បាប់សមាមាត្រកំណត់

អង្គធាតុសុទ្ធមួយ មានធាតុផ្សំក្នុងសមាមាត្រម៉ាសថេរជានិច្ច។ ឧ. ទឹក៖ H 11.11% និង O 88.89%។

ច្បាប់ពហុសមាមាត្រ

១.៣អ៊ីសូតូប

ប្រេងកាត និងឧស្ម័នធម្មជាតិ កើតពីសំណល់សត្វ និងរុក្ខជាតិសមុទ្រ ក្រោមសីតុណ្ហភាព និងសម្ពាធខ្ពស់ អស់រាប់លានឆ្នាំ។ វាជាឥន្ធនៈហ្វូស៊ីល ដែលមិនអាចកកើតឡើងវិញបាន។

  • ប្រេងកាតឆៅ៖ ល្បាយអ៊ីដ្រូកាបួច្រើនប្រភេទ (1 ដល់ 50 អាតូម C)
  • ឧស្ម័នធម្មជាតិ៖ ភាគច្រើនជាមេតាន (ប្រហែល 90%)
ចម្រាញ់ប្រភាគ
គេកំដៅប្រេងឆៅដល់ ~380 °C ក្នុងប៉មចម្រាញ់។ ចំហាយឡើងលើ ហើយកករួញនៅកម្ពស់ផ្សេងៗតាមចំណុចរំពុះ៖ ម៉ូលេគុលតូច (ចំណុចរំពុះទាប) ចេញនៅខាងលើ។
ក្រាកិញ (Cracking)៖ បំបែកម៉ូលេគុលធំ ឱ្យទៅជាម៉ូលេគុលតូចដែលត្រូវការច្រើន (ដូចជាសាំង)\[\ce{C5H12 -> C4H8 + CH4}\]

៤.២អ៊ីដ្រូកាបួឆ្អែត៖ អាល់កាន

រូបមន្តទូទៅ \[\mathrm{C}_n\mathrm{H}_{2n+2}\qquad(n\ge1)\qquad\text{មានតែសម្ព័ន្ធទោល }\mathrm{C{-}C}\text{ និង }\mathrm{C{-}H}\]
សាកល្បងរំកិលចំនួនអាតូមកាបូន \(n\)
ឈ្មោះ—
រូបមន្តម៉ូលេគុល—
ចំណុចរំពុះ—
សភាព (25 °C)—

ការហៅឈ្មោះ

ឫសតាមចំនួន C + បច្ច័យ «-ាន»៖ មេតាន, អេតាន, ប្រូប៉ាន, ប៊ុយតាន, ប៉ង់តាន …។ បណ្តុំ \(\mathrm{-CH_3}\) ហៅថា មេទីល។
ឧ. \(\mathrm{CH_3{-}CH(CH_3){-}CH_3}\)៖ 2-មេទីលប្រូប៉ាន

អ៊ីសូមែ

សមាសធាតុមានរូបមន្តម៉ូលេគុលដូចគ្នា តែរូបមន្តលាតខុសគ្នា។ ឧ. \(\mathrm{C_4H_{10}}\)៖ n-ប៊ុយតាន (រំពុះ −0.4 °C) និង មេទីលប្រូប៉ាន (−10.2 °C)។
ចំហេះពេញលេញ → CO₂ + H₂O + កម្តៅ\[\ce{CH4 + 2O2 -> CO2 + 2H2O}\]\[\ce{C3H8 + 5O2 -> 3CO2 + 4H2O}\]
ប្រតិកម្មជំនួស (ក្រោមពន្លឺ \(h\nu\))\[\ce{CH4 + Cl2 ->[h\nu] CH3Cl + HCl}\]បន្តជំនួសបាន៖ CH₂Cl₂ → CHCl₃ → CCl₄

៤.៣អ៊ីដ្រូកាបួមិនទាន់ឆ្អែត៖ អាល់សែន និងអាល់ស៊ីន

ការហៅឈ្មោះ៖ អាល់សែន បច្ច័យ «-ែន» (អេតែន, ប្រូប៉ែន, ប៊ុយ-1-អែន), អាល់ស៊ីន បច្ច័យ «-ីន» (អេទីន, ប្រូពីន)។ លេខបង្ហាញទីតាំងសម្ព័ន្ធពីរជាន់ ឬបីជាន់។

លក្ខណៈសំខាន់
សម្ព័ន្ធពីរជាន់ និងបីជាន់ ងាយបើកចេញ ដូច្នេះអាល់សែន និងអាល់ស៊ីន ធ្វើប្រតិកម្មបូក (សកម្មជាងអាល់កាន)។
បូកអ៊ីដ្រូសែន (កាតាលីករ Ni ឬ Pt)\[\ce{CH2=CH2 + H2 ->[Ni] CH3-CH3}\]
បូកប្រូម៖ ធ្វើតេស្ត ទឹកប្រូមពណ៌ត្នោត → បាត់ពណ៌\[\ce{CH2=CH2 + Br2 -> CH2Br-CH2Br}\]
ទ្រាតកម្ម (បូកទឹក) → អេតាណុល\[\ce{CH2=CH2 + H2O ->[H+] CH3-CH2OH}\]
ប៉ូលីមែកម្ម → ប្លាស្ទិក PE / PVC\[n\,\ce{CH2=CH2 -> }\,\big(\ce{CH2-CH2}\big)_n\]
ផលិតអាសេទីឡែន ពីកាល់ស្យូមកាប៊ួ\[\ce{CaC2 + 2H2O -> C2H2 ^ + Ca(OH)2}\]
ចំហេះអាសេទីឡែន ផ្តល់សីតុណ្ហភាព ~3000 °C (ផ្សារដែក)\[\ce{C2H2 + 5/2O2 -> 2CO2 + H2O}\]

៤.៤អ៊ីដ្រូកាបួក្រអូប៖ បង់សែន

បង់សែន \(\mathrm{C_6H_6}\)៖ អង្គធាតុរាវ គ្មានពណ៌ ក្លិនក្រអូប ងាយហើរ មិនរលាយក្នុងទឹក (ចំណុចរំពុះ 80.1 °C)។ សម្ព័ន្ធ C–C ទាំង 6 មានប្រវែងស្មើគ្នា ដូច្នេះវាមានស្ថិរភាព៖ ពេញចិត្តប្រតិកម្មជំនួស ជាងប្រតិកម្មបូក។

ដេរីវេ៖ តូលុយអែន \(\mathrm{C_6H_5CH_3}\), ផេណុល \(\mathrm{C_6H_5OH}\), អានីលីន \(\mathrm{C_6H_5NH_2}\), ស្ទីរ៉ែន \(\mathrm{C_6H_5CH{=}CH_2}\)។

ក្លរកម្ម (ជំនួស)\[\ce{C6H6 + Cl2 ->[FeCl3] C6H5Cl + HCl}\]
នីត្រាតកម្ម (ជំនួស)\[\ce{C6H6 + HNO3 ->[H2SO4] C6H5NO2 + H2O}\]
បូកអ៊ីដ្រូសែន (200–300 °C)\[\ce{C6H6 + 3H2 ->[Ni] C6H12}\]
ចំហេះ (អណ្តាតភ្លើងមានផ្សែងខ្មៅច្រើន)\[\ce{C6H6 + 15/2O2 -> 6CO2 + 3H2O}\]

៤.៥គីមីអនុវត្ត៖ ជីគីមី

រុក្ខជាតិត្រូវការធាតុចិញ្ចឹមសំខាន់ ៣៖ អាសូត (N), ផូស្វ័រ (P) និង ប៉ូតាស្យូម (K)។

ជីសរីរាង្គ

ជីទោល

មានធាតុចិញ្ចឹមតែ 1 ប្រភេទ។ ឧ. អ៊ុយរ៉េ \(\mathrm{CO(NH_2)_2}\), \(\mathrm{(NH_4)_2SO_4}\), \(\mathrm{NH_4NO_3}\), \(\mathrm{KCl}\)។

ជីសមាស

មានធាតុចិញ្ចឹម 2–3 (NP, NK, PK, NPK)។ ឧ. \(\mathrm{KNO_3}\) (NK), \(\mathrm{(NH_4)H_2PO_4}\) (NP)។
